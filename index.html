Find my project below:

  • Mini Project 1: Multitouch — Open demo
    This is a mini project where I adjusted the foundation code provided by the professor in the ABC Circus course at NYUSH.
    Features: draws one circle per active touch using p5.js touch events; circles follow each finger in real time; responsive canvas that resizes with the window.
  • Mini Project 2: Device Orientation (Gyroscope) — Open demo
    This demo uses the DeviceOrientation API (and a small permission request for iOS) to read the phone's orientation.
    Features: shows alpha/beta/gamma rotation values, requests permission on mobile, and rotates a visual element in real time—useful for tilt-controlled interactions and gyroscope-based visuals.
  • Mini Project 3: Simple Chat in Class — Open demo
    This is a mini project where I created a chatroom for the ABC Circus course at NYUSH.
    Features: when someone asks a question (ending with '?'), others can only respond with random Cards Against Humanity response cards; the asker chooses the best response, which appears publicly in the chat, while only the asker sees all responses and their authors.
  • Project 1: Juggling with Sockets — Farkle — Open demo
    Multiplayer dice game for two or more phones in real time (Socket.IO). On your turn you roll six dice: 1s = 100 pts, 5s = 50 pts, three-of-a-kind = 200–1000 pts, straight 1–6 = 1500 pts. You can Bank to add your turn total to your score and pass the dice, or keep rolling—but if a roll scores nothing (a “Farkle”), you lose that turn’s points. First to 10,000 wins.
    Deployed on the Hong Kong server; run node server.js before presenting and share the URL or a QR code.
